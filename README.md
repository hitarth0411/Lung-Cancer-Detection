# Lung Cancer Detection System

## About the Project

This project focuses on detecting lung cancer using artificial intelligence and machine learning techniques. The goal was to build a simple system that can analyze medical image data and help in identifying whether a patient may have lung cancer or not.

Early detection of lung cancer can make a huge difference in treatment outcomes. Through this project, I explored how deep learning and image classification models can assist in medical diagnosis.

The system takes lung scan images as input and predicts whether the image indicates signs of lung cancer.

---

## Motivation

Lung cancer is one of the leading causes of cancer-related deaths worldwide. Many cases are detected late because the early symptoms are not always obvious.

This project was created as an attempt to understand how AI models can help doctors and researchers analyze medical images faster and more efficiently.

It is not intended to replace medical professionals, but rather to demonstrate how AI can assist in healthcare applications.

---

## Features

* Image-based lung cancer detection
* Deep learning model for classification

## Tech Stack

The project was developed using the following technologies:

* Python
* TensorFlow / Keras
* NumPy
* OpenCV
* Streamlit (for interface)

---

## How It Works

1. The user uploads a lung scan image.
2. The image is preprocessed and resized to match the model input.
3. The trained deep learning model analyzes the image.
4. The system predicts whether the scan shows signs of lung cancer.
